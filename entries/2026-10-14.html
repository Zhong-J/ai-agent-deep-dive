证据装得下，怎么证明 Agent 真用对了？

从位置切片、非字面匹配和跨文档冲突，到 direct context、检索、摘要的路由与最终业务证据。

2026-10-14约 20 分钟Effective context / Long-context evaluation / RULER / Retrieval / Agent verification
01

今日命题

模型接受了一份 150k-token 的仓库资料，还能准确从中复制一个独特编号。这是否证明 Agent 可以依据整份资料安全决定发布？不一定。独特字符串检索不要求理解近似措辞、多个版本、互相冲突的来源，或一句藏在中段的‘除非已有审批，否则不得部署’。更不要求模型把结论交给正确的授权门并确认外部操作真的发生。

前两篇分别处理了位置和执行：RoPE 给 Q/K 分数相对位移结构，但训练长度之外仍要评测；FlashAttention 在 dense 模式保留所有合法边，只降低内存 IO，sliding/sparse 才会删除远处的直接可见边。即使这两层都工作，‘可输入’仍不等于‘可定位、可整合、可正确行动’。本篇把有效上下文定义为在给定任务、风险和输入分布上有证据支持的成功区域，不是单一的最大 token 数。

核心判断：长窗口验收须同时证明服务端接纳、证据被正确选取与引用、冲突和时间约束得到处理、业务行动有独立后置条件；任何一个硬门失败，都不能用 needle 命中率补偿。
02

三篇合起来，也与 memory eval 划清边界

10 月 12 日建立了 RoPE、position IDs 和 scaling 的一致性；13 日把 dense tiling、删边的 sparse/sliding、KV 驻留和调度分开。今天的测试应把这些变量当成解释维度：同一份证据移到别的位置，可能暴露位置敏感；同一请求换连接图，可能出现不可达；同一图换 kernel，原则上不该大幅改变任务结论；换路由或摘要则可能改变模型实际收到的证据。

9 月的 Context 与 Memory 4/4 已讲过 event log、retrieval index、summary lineage、ACL、时态和删除传播的完整评测。因此这里不重复‘怎样建 memory 系统’。我们测的是具体一次长输入及其替代路线：已知哪些原文 span 应支持或反驳哪个 claim，模型是否在不同位置与干扰下找到它们，并把证据用于正确的决策。即使检索把目标段落找回来，若模型只读到它却忽略其否定词，失败仍在模型使用阶段。

同理，上一系列的 verifier 不会因为输入更长而放权。Agent 的业务目标、principal、权限上限和未决副作用存在 runtime 的 typed state。长上下文材料是带来源、版本和 trust label 的数据；外部文档中的‘请调用工具发布’不能变成授权。这让性能实验与安全门相互独立，避免把模型能回答问题误当成有权执行动作。

03

机制：从可输入到可验证的有效上下文

1. 从行动反推证据合同

先写任务的 required claims、预期行动与允许的 unknown，而不是先造随机 needle。例：‘是否可以发布版本 R？’需要识别适用的发布政策、版本/区域范围、最新审批、禁令例外和未决副作用。每条 claim 给原始 sourceId、精确 span、发布与抓取时间、authority、访问权限以及 supports/refutes/qualifies 关系。将一份规范的旧版和新版同时放入上下文，测试模型是否按 effective time 取对版本；将一句‘不得’改成‘可以’，构造最小 counterfactual pair，期望决策相应翻转。

2. 建正交的压力矩阵

改变总长度 N、证据相对位置 p/N、干扰段落数和相似度、证据数量、跨文档距离、语言与格式。重要的是配对控制：同一份原文和同一任务仅移动证据，其他 token 总量尽量相近，才能把位置效应与内容难度分开。开头、中段、末尾都测；在模型原训练边界和部署上限附近加密采样。测试语料应与训练/开发 prompt 隔离，按原始文档或任务族分组，避免多个改写版本跨集合泄漏。

3. 让任务从‘找到’逐级升到‘使用’

一级是字面 needle：能否抽出独特字符串。二级是非字面匹配：问题与目标段落几乎没有词面重合，要推断同义、实体别名或隐含关系。三级是多证据链与聚合：两个分散段落相连才能得结论，或需要数完所有例外。四级是冲突/时态：优先适用版本、保留反证、在证据不足时 abstain。五级是 Agent 行动：在前四级正确的前提下，仍需检查 tool 参数、授权和远端后置条件。RULER、NoLiMa、BABILong、LongBench 等作者 benchmark 分别覆盖部分层次；任何一个分数都不能代替完整合同。

4. 每层留可判定观测

首先记录服务端是否接纳输入、实际 tokenization、是否静默截断、位置配置、attention 图和 prefix cache 版本。再记录 context assembler 实际提交了哪些 source spans；若检索路线存在，区分候选召回、ACL/时间过滤、最终入 prompt。最终答案的每个关键 claim 必须指向可回源 span，由独立检查判定引用是否蕴含该 claim，并保存 unknown/反证。若发起写操作，还要用业务 ID 或权威系统状态核验外部 effect。最终答对一次却引用错段，仍不是 evidence-qualified success。

5. 用 first divergence 定位故障

五道门依次是 admission、reachability、selection、integration、effect。请求被拒或 OOM，属服务能力；证据在被截断的尾部或局部 attention 图外，属可达性；证据可达却未被选中，属定位；选中仍忽略否定、时间或冲突，属整合；答案正确而误用工具、重复提交或未核对远端，属 runtime/effect。Attention heatmap 不是充分因果证据，不能凭某个权重解释错误；用 controlled move、counterfactual 和 stage trace 比单张热图更强。

6. 为三条路线做同一任务的配对赛

Direct context 保留整份原文，适合需要跨全局综合且输入可服务、位置回归过关的任务，代价是 prefill、KV 与干扰。Retrieval 适合目标证据稀疏、可检索定位的任务，代价是召回漏失、切块断链与 index 时效。Summary 适合重复历史和导航，但有损改写不得承载硬约束；关键 claim 须 rehydrate 原文。Hybrid 可先检索候选，再给模型一个较短但包含相互冲突来源的证据包。四者在相同权限、时间切片和业务 oracle 下比 verified success、引用、成本和尾延迟；不要因模型自报 confidence 选择路线。

7. 用风险门和线上漂移收尾

小概率严重错误不能被大量容易的 needle 成功平均掉。发布或外部写入等动作设置 hard gate：必需的禁止条件、授权版本和未决副作用只要 unknown，就不能自动执行。离线测试通过后，shadow/canary 仍要按任务、位置、长度与 route 监控漂移；真实文档分布、新模板、模型升级和不同用户的 ACL 都可能改变有效窗口。只保存必要的 span/digest 与脱敏 trace，不能为评测把用户机密随意复制到公开基准。

04

必要数学：有效长度是一个条件区域

记 S(N,p,t,r) 为在长度 N、证据相对位置 p∈[0,1]、任务切片 t、输入路线 r 下，required claims 均通过独立验证且没有硬安全门失败的成功率。分母是该切片全部预注册案例，包括拒绝、超时与 unknown，而非只算模型给出答案的案例。p=0.5 是中段；t 可区分字面匹配、多证据链、时间冲突或高风险行动。RULER 等研究提示 NIAH 成绩不可靠预测更复杂任务，但 S 必须在自己的工作负载上估计。

给定可接受阈值 τ 和证据位置集合 P，定义一个已测试网格上的有效长度：N_eff(t,r;τ)=最大的已测试 N，使 min_{p∈P} LCB[S(N,p,t,r)]≥τ，且所有 hard gates 通过。LCB 是按来源/任务族聚类估计的成功率置信下界，不是模型自报概率。取最差位置防止末尾高分掩盖中段低分；有限样本和未测长度意味着这不是未来任务的保证。若某高风险切片没有足够样本，应标 unknown，而非宣称满足阈值。

比较路线还要计代价。可用 U(r)=V·P_verified(r)−C_token(r)−C_latency(r)−L_error(r) 表示：V 是一次经验证正确结果的价值，P_verified 是实测成功概率，C 是 token 与延迟成本，L_error 是错误损失。只在 ACL、授权、deadline 和 hard evidence policy 全满足的路线中最大化 U；‘便宜’不能买断越权风险。配对案例下再计算中段与末尾差 Δ_mid=S_mid−S_end，用同一内容移动位置，避免把样本难度误认为位置效应。

05

对 Agent 系统的影响

能力：长窗口扩大候选证据集合，但有效区域随任务、证据位置和干扰而变。需要全局综合时 direct context 可能有优势；目标稀疏时检索更省；多轮历史可用带 source refs 的摘要导航。没有一条路线普遍胜出。

可靠性：把输入接纳、证据入 prompt、正确引用、决策和 effect 各自记录，能看见‘模型答对但引用错’或‘答对却越权’。RoPE/attention/kernel 变更必须带版本，以配对回归捕获位置和路径退化。

成本：长直接输入增加 prefill 与 KV 压力；检索与摘要增加索引维护、重建、误召回和人工复核成本。以每个 verified outcome 的总成本而非每千 token 单价比较路线，包含失败重试与尾延迟。

安全：更多原始文档同时扩大 prompt-injection 面。文档内容只作 evidence，不提升 tool 权限；硬约束和未决副作用仍由 runtime 管。有效上下文评测不能替代授权机制。

06

取舍与失败模式

  • needle 高分当作全局理解：字面匹配跳过非字面关联、多跳、冲突和行动；逐级增加任务难度。
  • 只测末尾位置：尾部高分掩盖中段退化；同一证据成对移动并保持长度相近。
  • 总分掩盖风险切片：多数低风险问答成功不能抵消一次错误发布；hard gate 单独判。
  • 引用 URL 不引用 span：正确文件未必支持 claim；做版本、时间与 entailment 检查。
  • 检索召回就算成功：选入 prompt 后仍可能被模型忽略或误整合；分 stage 测。
  • 摘要替代原始约束：有损改写可能删掉否定词；不可丢状态外置，关键决策回源。
  • 公开基准调到满分：重复试探和同源案例泄漏会高估泛化；封存测试并做真实 canary。
  • 能答等于能执行：外部动作另有权限、幂等与后置条件；verifier 而非模型决定完成。
07

可复用的技术判断

  • 标称窗口、可服务窗口、有效任务窗口不同；有效长度应按位置、任务、路线和风险报告。
  • 测试从字面定位升到非字面关联、多证据、冲突/时态与外部行动，保留原文 span oracle。
  • 同一证据的成对位置移动、否定词翻转与路线对照，比单次 needle 分数更能诊断失败。
  • direct、retrieval、summary 与 hybrid 按 verified outcome、成本和硬约束选择，不听模型自报把握。
  • 长上下文的终态仍由独立 verifier、授权和外部业务证据决定。
08

一手资料与证据等级

  • Lost in the Middle — 作者在多文档 QA 和 key-value 检索中报告位置敏感；不是所有模型任务必呈相同曲线。
  • RULER — 作者把简单 needle 扩展为多针、多跳和聚合，并报告长度增加后的退化。
  • NoLiMa — 作者设计低词面重合的关联定位任务，报告长上下文性能下降。
  • BABILong — 作者将分散事实放进长自然文本，测试多类推理；其百分比是作者实验，不是通用有效窗口。
  • LongBench 与 ∞Bench — 双语、多任务和超长输入的作者 benchmark，覆盖面与标注仍依各自设计。
  • HELMET — 作者比较多种长上下文任务，指出单一 synthetic needle 与应用表现的相关性有限。

本文的五道验证门、N_eff 门槛和 Agent 路线决策是编辑性工程框架；引用研究提供可检验的失败模式，不替具体产品证明安全。

The Evidence Fits. How Do You Prove the Agent Used It?

From position slices, nonliteral matching, and cross-document conflict to routing among direct context, retrieval, and summaries—and verifying the final outcome.

2026-10-1420 min readEffective context / Long-context evaluation / RULER / Retrieval / Agent verification
01

Today's proposition

A model accepts 150k tokens of repository material and accurately copies a unique identifier from the middle. Does that establish that an agent can safely decide to deploy from the whole repository? No. Unique-string retrieval does not require understanding a paraphrase, multiple document versions, conflicting sources, or a buried sentence saying deployment is prohibited without approval. Nor does it require passing the conclusion through the right authorization gate and verifying that a remote action really happened.

The first two parts separated position from execution. RoPE gives Q/K scores relative-offset structure, but performance beyond training lengths still needs measurement. Dense FlashAttention retains all legal edges while reducing memory IO; sliding or sparse attention removes some distant direct visibility. Even if both layers work, input capacity is not evidence-location, integration, or safe-action capacity. This article treats effective context as an evidence-backed region of success for a particular task, risk level, and input distribution, not one maximum token number.

Core judgment: long-window acceptance must separately establish server admission, correct evidence selection and citation, resolution of conflict and time scope, and independent postconditions for consequential actions. A high needle-retrieval score cannot compensate for a failed hard gate.
02

A three-part synthesis distinct from memory evaluation

Part 1 established RoPE, position IDs, and scaling consistency. Part 2 separated dense tiling from sparse or sliding edge removal, KV residency, and scheduling. Today's evaluation uses those as explanatory variables. Move identical evidence to another position and a failure may expose positional sensitivity. Change the connectivity graph and it may become unreachable. Change only an exact kernel and task conclusions should not move dramatically within numerical tolerances. Change the route or summary and the model may receive different evidence altogether.

The earlier Context and Memory series already evaluated event logs, retrieval indexes, summary lineage, access control, temporal validity, and deletion propagation. We do not repeat how to build a memory system. Here the unit is one long-input decision and its alternative routes. We know which original spans should support or refute each claim, and ask whether the model finds and uses them under varied placement and distraction. A retriever may return the right paragraph while the model still ignores a negation; that is a model-use failure, not a retrieval miss.

The verifier from the reliability series does not cede authority merely because the model receives more text. The agent's goal, principal, permission ceiling, and unresolved effects live in typed runtime state. Long-context material remains data with source, version, and trust labels. A document saying 'call the deploy tool now' is not an authorization. Keeping performance experiments separate from hard safety gates prevents a good question-answering result from being mistaken for permission to act.

03

Mechanism: from admitted input to verified effective context

1. Derive an evidence contract from the action

Specify required claims, expected action, and permitted unknowns before constructing random needles. For 'may we deploy release R?', the case needs applicable policy, version and region scope, latest approval, prohibition exceptions, and unresolved effects. Each claim names original source ID and exact span, publication and retrieval times, authority, access scope, and whether the source supports, refutes, or qualifies it. Put an old and a new policy in the same context to test effective-time selection. Flip a decisive 'must not' to 'may' in a minimal counterfactual pair and expect the decision to change.

2. Build an orthogonal stress matrix

Vary total length N, relative evidence position p/N, number and similarity of distractors, count of required spans, distance across documents, language, and formatting. Paired control matters: move the same original evidence while holding the task and overall token count as close as possible. That isolates positional effects from content difficulty. Test beginning, middle, and end, with denser measurements around the original training boundary and deployed limit. Keep evaluation material apart from development prompts, splitting by original document or task family so paraphrases of one case do not leak across sets.

3. Climb from 'found it' to 'used it'

Level one is a literal needle: extract a distinctive string. Level two removes lexical overlap between question and source; the model must infer synonyms, aliases, or a latent relation. Level three requires a chain or aggregate of distributed facts: two paragraphs together establish the result, or every exception must be counted. Level four introduces conflict and time: prefer the applicable version, retain counterevidence, and abstain when evidence is insufficient. Level five requires agent action: even with the right interpretation, tool arguments, authorization, and remote postconditions must be checked. Author benchmarks such as RULER, NoLiMa, BABILong, and LongBench cover portions of this ladder. No one score implements the entire contract.

4. Leave adjudicable observations at each layer

First log server admission, actual tokenization, silent truncation, position configuration, attention graph, and prefix-cache version. Record which source spans the context assembler submitted. On a retrieval route, distinguish candidate recall, ACL or time filtering, and final prompt inclusion. Every consequential final claim should cite an original span. An independent checker decides whether that span entails the claim and preserves unknowns and refutations. If the agent writes to an external system, verify the effect through a business ID or authoritative system state. One correct answer with a wrong citation is not evidence-qualified success.

5. Attribute the first divergence

The five gates are admission, reachability, selection, integration, and effect. A rejected request or out-of-memory failure is service capacity. Evidence beyond a truncated boundary or outside a local attention graph is reachability. Reachable evidence that is never selected is location failure. Selected text whose negation, time scope, or conflict is ignored is integration failure. A correct answer followed by a wrong tool call, duplicate submit, or absent remote check is runtime or effect failure. An attention heatmap alone is not sufficient causal evidence for any category. Controlled placement changes, counterfactuals, and stage traces support a stronger diagnosis.

6. Run paired trials for input routes

Direct context retains the full original material and suits broad synthesis when it is serviceable and position tests pass; it pays prefill, KV, and distractor costs. Retrieval suits sparse, locatable evidence, but may miss a source, sever a cross-chunk chain, or use a stale index. Summary helps navigate repeated history but is a lossy rewrite and cannot carry hard constraints alone; rehydrate originals for critical claims. A hybrid route may retrieve candidates and send a shorter evidence pack that still includes conflicting sources. Compare routes on the same authorization and temporal slice, judging verified success, citations, cost, and tail latency. A model's self-reported confidence is not the route oracle.

7. Close with risk gates and drift

A rare catastrophic action cannot be averaged away by many easy needle successes. External writes and releases need hard gates: if a mandatory prohibition, authorization version, or unresolved effect remains unknown, do not execute automatically. After offline evaluation, shadow and canary runs still monitor by task, evidence position, length, and route. Real document distributions, new templates, model revisions, and user-specific ACLs can change the effective window. Retain only necessary spans, digests, and de-identified traces; evaluation does not justify copying user secrets into a public benchmark.

04

Essential mathematics: effective length is a conditional region

Let S(N,p,t,r) be the rate at which all required claims receive independent verification and no hard safety gate fails, for length N, relative evidence position p in [0,1], task slice t, and input route r. The denominator includes every pre-registered case in that slice: refusals, timeouts, and unknown outcomes are not discarded merely because the model failed to answer. p=0.5 denotes the middle. Task slice t may distinguish literal lookup, multi-evidence chaining, temporal conflict, or high-risk action. Research such as RULER warns that a needle score may poorly predict harder tasks, but S must be estimated on the actual workload.

For acceptance threshold τ and a tested position set P, define an effective length on the evaluated grid: N_eff(t,r;τ) is the largest tested N for which min over p∈P of LCB[S(N,p,t,r)]≥τ and all hard gates pass. LCB is a lower confidence bound on success estimated with clustering by source or task family, not the model's self-reported probability. Taking the worst tested position prevents a high end-of-prompt score from concealing a weak middle. Finite samples and untested lengths mean this is not a guarantee for future tasks. If a high-risk slice lacks enough cases, its status is unknown, not pass.

Routes also have different economics. Write U(r)=V·P_verified(r)−C_token(r)−C_latency(r)−L_error(r). Here V is the value of one verified success, P_verified an empirically measured success probability, C terms token and latency costs, and L_error expected error loss. Maximize U only among routes satisfying ACL, authorization, deadline, and hard evidence policy. Cheapness cannot purchase permission to violate a hard boundary. With paired cases, also compute the middle-versus-end difference Δ_mid=S_mid−S_end while moving the same content, so case difficulty is less likely to masquerade as a position effect.

05

Implications for agent systems

Capability: a long window enlarges the candidate evidence set, but the effective region varies by task, evidence position, and distraction. Direct context may help broad synthesis; retrieval can be cheaper for sparse targets; source-linked summaries can navigate repeated history. No route wins universally.

Reliability: recording admission, prompt inclusion, citation, decision, and external effect separately reveals 'correct answer, wrong citation' and 'correct answer, unauthorized action.' Version position rules, attention graphs, and kernels so paired regressions can detect positional or path failures.

Cost: long direct input adds prefill and KV pressure. Retrieval and summaries add index upkeep, rebuilds, misses, and review cost. Compare total cost per verified outcome rather than unit price per thousand tokens, including retries and tail latency.

Safety: more raw documents also enlarge the prompt-injection surface. Document content remains evidence, not tool authority. Runtime retains hard constraints and unresolved effects. Effective-context evaluation cannot replace authorization.

06

Trade-offs and failure modes

  • Needle success treated as whole-context understanding: literal match skips latent association, multihop, conflict, and action. Climb task difficulty in stages.
  • Only testing the end: a strong tail score hides middle degradation. Move paired evidence while keeping length comparable.
  • Average score hides a risky slice: many harmless QA wins cannot compensate for a mistaken deployment. Judge hard gates separately.
  • URL citation without a span: the right document may not support a claim. Check version, time, and entailment.
  • Retrieval recall counted as success: once in the prompt, evidence may still be ignored or misintegrated. Measure every stage.
  • Summary replaces an original constraint: lossy rewriting may drop a negation. Externalize invariants and rehydrate for critical decisions.
  • Public benchmark tuned to perfection: repeated probing and same-source leakage inflate generalization estimates. Protect a sealed test and run real canaries.
  • Can answer, therefore may execute: external actions have separate permission, idempotency, and postconditions. The verifier—not the model—decides completion.
07

Reusable technical judgments

  • Advertised, serviceable, and task-effective windows differ; report effective length by position, task, route, and risk.
  • Test literal lookup, latent association, multi-evidence reasoning, conflict and time, then external action with original-span oracles.
  • Paired placement moves, negation flips, and route comparisons diagnose failures better than one needle score.
  • Choose direct, retrieval, summary, or hybrid routes by verified outcomes, cost, and hard constraints—not model confidence.
  • Independent verification, authorization, and external business evidence still determine the terminal state.
08

Primary sources and evidence tiers

  • Lost in the Middle — the authors report position sensitivity in multi-document QA and key-value retrieval, not a universal curve for every model or task.
  • RULER — the authors extend simple needles to multiple needles, tracing, and aggregation, and report degradation with length.
  • NoLiMa — the authors design low-lexical-overlap association tasks and report long-context declines.
  • BABILong — the authors scatter facts through long natural text and test several reasoning types. Their percentages are experimental results, not a universal effective window.
  • LongBench and ∞Bench — author benchmarks with bilingual, multitask, and very long inputs; coverage and labeling follow their own designs.
  • HELMET — the authors compare diverse long-context tasks and find a single synthetic needle is a limited predictor of application performance.

The five verification gates, N_eff acceptance rule, and agent route policy are editorial engineering design. These sources expose testable failure modes; they do not certify a particular product as safe.

09

Three-part synthesis: Part 1 explained RoPE phase and limits of length extrapolation. Part 2 separated IO-aware tiling of dense attention from sparse or sliding edge removal, accounting for KV and serving limits. Part 3 uses a task-by-length-by-position-by-distractor-by-route matrix to verify admission, reachability, location, integration, and external effect. '128k' is no longer a single marketing number; it becomes a falsifiable, task- and risk-scoped capability claim.
