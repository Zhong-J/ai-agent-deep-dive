语音 Agent 听到一句话，模型到底接收了什么？

从波形、声学帧、转写文本到 codec token，解释语音接入的两类路径、信息损失与 Agent 行动边界。

2026-10-27约 20 分钟Speech agents / ASR / Log-Mel / Neural codec / Audio tokens / Speech-to-speech
01

今日命题

用户对语音 Agent 说‘不要取消订单’，转写器却漏掉一个‘不’，下游 LLM 很认真地调用取消工具。把语音接到 Agent 并非‘给 prompt 加一支麦克风’：连续波形要经过采样、分帧、特征抽取或音频 tokenizer，再变成模型可处理的表示。某些系统先 ASR 转文字、用文本 LLM 推理、再 TTS 发声；另一些模型在语言与音频表示间直接建模。两条路径保留的信息、暴露的错误和可审计边界不同。

今天开始 Audio & Realtime Agent Internals 1/3，从波形与 log-Mel 声学帧讲到 transcript 和 neural codec token。核心不是选某个产品，而是理解：为何转写文本不是原始音频的无损摘要，音频 token 又为什么不等于文字 token；口音、语气、重叠说话和环境噪声怎样进入模型错误；Agent 什么时候只能记录候选意图，不能据此执行不可逆工具动作。第二篇再专讲流式 turn-taking、端点检测与打断；第三篇综合评估和安全。

核心判断：语音是带时间、说话人和声学不确定性的信号。把它压成一行文本可能方便推理与审计，也可能丢掉决定行动语义的细节。
02

承接 LLM token 与 Agent 工具合同

此前我们把文字 LLM 的 token、Transformer、teacher forcing 和 decode 区分开。音频首先不是离散词：麦克风在每秒固定次数测量振幅，同一句话的时长、停顿、音高和背景声都会改变样本序列。若先做 ASR，文本 LLM 接到的是识别器的假设，而不是用户的原话；若直接处理音频，模型也要把声学特征压缩成有限表示。两者都可能产生幻觉或漏掉否定词，不能把‘模型听到了’当作来源精确性的证明。

Agent runtime 已有 tool schema、授权、幂等与恢复。语音增加一个身份与时间边界：扬声器里别人的声音、播放的录音和用户的实时指令，在波形上都可能是‘话’。ASR 的 partial transcript 尤其会在后续帧到达时被改写。系统可以提前准备候选回复，但不能让未经确认的片段直接触发付款、删除或发送消息。工具动作的授权来自用户与外层策略，不来自语音模型的自信或语调。

03

机制：波形进入语言推理的两类路线

1. 采样与声学特征

原始 PCM 是随时间排列的振幅样本。前端可以做重采样、声道合并、降噪、分帧，再用短时傅里叶变换估计频谱并投影到 Mel 频带，得到 log-Mel 特征。它保留了较多音色与时间结构，但并非无损；相位、极细的波形差异和部分背景信息会被压缩。Whisper 原论文从 log-Mel 声学输入训练 encoder-decoder 转写/翻译等任务，结果属其数据与评测。系统若把它的输出当作不可修改的真文字，错误就会成为下游 Agent 的假前提。

2. 转写级联让边界清晰，也引入瓶颈

ASR 可输出转写或候选文字；一些接口还提供词或片段时间戳与不确定性，若可用应保留；文本 LLM 在这些 token 上做意图理解与工具规划；TTS 再合成回复。级联好处是可展示和审计文字、可以复用文本 Agent 的 tool schema，容易在动作前让用户确认。代价是转写错误会传递到意图与回复，语气、说话人、笑声或停顿可能不在文字里。ASR 与 TTS 分开也有等待和同步成本；不能从一篇 ASR 论文直接推断整条语音链的响应延迟。

3. Codec token 与联合语音文本建模

neural audio codec 把波形编码为压缩的离散符号序列，decoder 再近似还原音频；它的 token 可承载更多声学细节，不是‘一个 token 等于一个字’。EnCodec 论文研究高保真神经音频压缩，AudioLM 以音频语言建模生成连续声音；SpeechT5、AudioPaLM 和 Moshi 分别探索语音/文本共享、联合或实时对话的不同架构。这里不能把它们混称单一端到端方案。联合建模可能保留语调、非言语声或生成节奏，但每条路线有自己的训练覆盖、codec 失真和延迟约束；保留声学信息也不自动证明听懂意图。

4. 文本、声学与说话人是不同证据

‘我说了什么’、‘谁说的’、‘带什么情绪/强调’是三个问题。转写器可给词，声纹或 diarization 可给候选说话人段落，声学模型可保留语气；这些结果都可能不确定。重叠说话、回声、播放录音和环境电视可污染上下文。对 Agent，音频来源/时间段、转写版本和置信或候选分歧应随 trace 保存，便于动作争议时回溯；但录音可能涉及敏感内容，保留要按用户同意和数据政策限制。

5. 何时可以进入工具决策

识别器的增量片段可用于低风险准备，例如预测用户可能要查询订单；最终承诺动作需要完整上下文与外层授权。一个暂时识别为‘取消’的前缀，后续可能变成‘不要取消’。若已有明确用户身份/许可，模型仍需确认工具参数与后置条件；若身份不能独立确认，声纹相似或‘听起来像老板’不应授予高风险权限。下一篇会细讲何时判定 turn 结束和如何被用户打断。

04

必要数学：从采样率到模型时序

持续 T 秒、采样率 f_s Hz 的单声道波形约有 N=f_s·T 个样本。f_s 是每秒测量次数，不是模型 token/s。若每样本以 16 bit 存储，未压缩载荷为 B≈N·16/8 字节。10 秒、16 kHz 例子有 160,000 样本、约 320,000 字节；声道数翻倍则载荷翻倍。这个计算仅说明输入带宽，不是 codec 码率、推理费用或识别质量。

若声学特征每 H 个样本向前移一帧，帧率约为 r≈f_s/H。16 kHz 采样且 H=160，则约 100 帧/秒；10 秒约 1000 帧。短时傅里叶变换估计每帧频率能量，经 Mel 滤波和 log 得到二维特征。可记为 M=log(ε+Mel(|STFT(x)|²))：x 是波形，STFT 是短时频谱，|·|² 是功率，Mel 是滤波器组，ε 避免零取对数。这个映射丢失相位且压缩频率细节；后续 encoder 还可能下采样。声学帧数不等于 LLM 输入 token 数。

在一个自回归 ASR decoder 中，给定音频表示 x，文字序列 y 的条件概率可拆为 P(y|x)=∏ₜP(yₜ|y₍<ₜ₎,x)。yₜ 是当前文字 token，前面的转写会影响后面的预测；这解释为何局部听错可能改变整句。数学只描述一种生成式转写路线，不代表所有 ASR 都用同一目标。工程上应保存带时间的候选与终稿，并在否定、金额、姓名和工具参数上提高确认门槛。

05

对 Agent 的影响：证据、身份与行动分开

语音输入工具应返回结构化 observation：音频片段 ID、起止时间、采样/预处理版本、ASR 候选或音频 token 路线、说话人分段、终稿状态和保留期限。下游 LLM 不应只看到一行去掉时间的文字；至少在高风险任务里，它要知道哪些词不确定、是否多说话人、该句是 partial 还是 final。若只保留 codec token 而没有可审计的转写或语义记录，事后调查工具为何执行会更难。

从意图到工具调用还要经过独立授权：语音内容可以提出‘取消订单’，但不能凭声纹或背景播报授予订单权限。对金额、否定、联系人和删除等高损失参数，可以用文本/语音复述让用户确认，或要求已有强身份会话/审批。确认也要绑定具体参数与请求版本，避免用户确认了旧转写而 Agent 执行了后来改写的新意图。

比较 ASR→LLM→TTS 与更直接的音频模型时，保持相同任务、权限、语言/口音、噪声和工具合同。分别量转写/语义错误、说话人归属、语气敏感问题、工具参数精度、TTFT/端到端延迟、打断恢复和每个 verified outcome 成本。把‘听感自然’与‘工具安全’分列；更流畅的声音可能掩盖同样的意图误解。

06

取舍与失败模式

  • 转写文本就是原音频：说话人、语气、停顿与噪声信息可能丢失；必要时保留受控音频引用。
  • 音频 token 就是文字 token：codec 符号表达声学片段，不按字词一一对应；勿用文字 token 账本估延迟。
  • ASR partial 可直接执行：后续语音可能加否定或修正；高风险动作等终稿和授权。
  • 联合模型天然更懂语气：保留音频不保证训练覆盖和推理使用；按任务实测。
  • 声音像授权用户：录音重放、扬声器和模仿都可能出现；独立身份与许可门。
  • WER 低就能安全用工具：平均转写错误率可能掩盖金额、姓名和否定的关键错误；测参数与终态。
  • 保留所有录音便于 debug：敏感声纹和第三方声音需同意、限期与最小访问。

级联路线提供较清晰的文字审计点，却可能放大转写错误；更直接的语音路线保留声学细节，却提高验证和归因难度。没有一条路径在所有语言、噪声、风险和实时性条件下自然占优。

07

可复用的技术判断

  • 波形、声学帧、转写文本和 codec token 是不同表示，不能当成同一种 token。
  • ASR→LLM→TTS 的文字边界易审计但会传递转写损失；联合音频路线保留更多声学线索也有新成本。
  • partial transcript 是可修正假设，不是高风险工具的执行依据。
  • 说话内容、说话人身份和工具授权分开验证，声纹或语气不能单独授权。
  • 验收要切到否定、金额、姓名、噪声与重叠说话，最终看 verified task outcome。
08

一手资料与证据等级

  • Robust Speech Recognition via Large-Scale Weak Supervision (Whisper) — 作者研究 log-Mel 输入的多任务语音识别/翻译；其准确率属论文评测。
  • High Fidelity Neural Audio Compression (EnCodec) — 作者提出神经音频压缩与离散 codec 表示。
  • AudioLM — 作者研究基于音频 token 的生成；不代表所有语音 Agent 架构。
  • SpeechT5 与 AudioPaLM — 作者分别探索语音/文本统一或联合建模。
  • Moshi — 作者报告实时语音文本对话模型；延迟与交互数字限其系统实验。

When a Voice Agent Hears a Sentence, What Does the Model Receive?

Trace waveforms through acoustic frames, transcripts, or codec tokens to understand two speech-model paths, their information loss, and the agent action boundary.

2026-10-2720 min readSpeech agents / ASR / Log-Mel / Neural codec / Audio tokens / Speech-to-speech
01

Today's proposition

A user tells a voice agent, 'Do not cancel the order.' The recognizer drops 'not,' and the downstream LLM diligently calls a cancellation tool. Connecting speech to an agent is not merely adding a microphone to a prompt. Continuous waveforms are sampled, framed, and turned into acoustic features or audio-token representations before a model can use them. Some systems transcribe with ASR, reason with a text LLM, and speak with TTS. Others model language and audio representations more directly. These paths preserve different information, expose different errors, and create different audit boundaries.

Audio & Realtime Agent Internals begins at representation: waveform, log-Mel acoustic frames, transcript, and neural-codec tokens. The aim is not to select a product. We need to understand why a transcript is not a lossless summary of audio, why an audio token is not a word token, how accent, prosody, overlap, and noise become modeling errors, and when an agent must treat intent as a proposal rather than authorization for an irreversible tool call. Part 2 will handle streaming turn-taking, endpointing, and interruption. Part 3 will evaluate quality and safety end to end.

Core judgment: speech is a time-varying signal with speaker and acoustic uncertainty. Reducing it to one line of text can aid reasoning and audit while discarding details that determine action meaning.
02

Connecting LLM tokens and agent tool contracts

Earlier lessons separated text tokens, Transformer processing, teacher forcing, and decoding. Audio is not initially a sequence of discrete words. A microphone samples amplitude at a fixed rate; duration, silence, pitch, and background sound change the samples even when the words are the same. In an ASR-first path, the text LLM receives the recognizer's hypothesis, not a perfect copy of the user's utterance. In a direct-audio path, the model still compresses acoustic information into finite representations. Either route can hallucinate or miss a negation. 'The model heard it' is not proof of an accurate source transcript.

The agent runtime already has tool schemas, authorization, idempotency, and recovery. Speech adds identity and time. A bystander, a replayed recording, and a live user command can all look like speech in a waveform. Partial ASR hypotheses may be revised as later frames arrive. The system can prepare candidate responses early, but unconfirmed fragments should not trigger payment, deletion, or messaging. Tool authority comes from the user and outer policy, not from a speech model's confidence or vocal tone.

03

Mechanism: two routes from waveform to language reasoning

1. Samples and acoustic features

Raw PCM is an ordered series of amplitude measurements. A front end can resample, merge channels, denoise, and frame it, then use a short-time Fourier transform to estimate spectra and project them onto Mel-frequency bands before taking logs. Log-Mel features retain substantial timing and timbre structure, but are not lossless; phase, fine waveform differences, and some background detail are compressed away. The original Whisper work trains an encoder-decoder on log-Mel input for transcription, translation, and related tasks. Its results are from its training and evaluation. Treating its output as immutable ground-truth text turns recognition error into a false premise for the agent.

2. A transcription cascade clarifies boundaries and adds bottlenecks

ASR emits a transcript or candidates; some interfaces also expose word- or segment-level timing and uncertainty, which should be retained when available. A text LLM reasons over those tokens and plans tool use. TTS synthesizes the response. The cascade makes text visible and auditable, reuses text-agent schemas, and can ask the user to confirm before action. Recognition errors propagate into intent and output, however, while prosody, speaker cues, laughter, and pauses may disappear from the transcript. Separate ASR and TTS also add waiting and synchronization costs. An ASR paper alone cannot establish latency for the entire speech-agent pipeline.

3. Codec tokens and joint speech-text modeling

A neural audio codec encodes waveforms into compressed discrete symbol sequences and approximately reconstructs audio with a decoder. Its tokens can retain more acoustic detail; one token does not equal one word. EnCodec studies high-fidelity neural audio compression. AudioLM models audio as language-like tokens for coherent generation. SpeechT5, AudioPaLM, and Moshi explore different shared, joint, and real-time speech-text architectures. They should not be collapsed into one end-to-end implementation. Joint modeling can carry prosody, nonverbal sounds, or timing, but each design has its own training coverage, codec distortion, and latency. Preserving acoustic information does not automatically prove intent understanding.

4. Text, acoustics, and speaker are separate evidence

'What was said,' 'who said it,' and 'with what emphasis' are different questions. An ASR model proposes words. Diarization or speaker analysis proposes speaker segments. An acoustic path may retain emphasis and tone. Each can be uncertain. Overlapping speakers, echo, replayed recordings, and background television can contaminate context. A speech agent should retain audio source and time span, transcript version, and candidate disagreement or confidence in its trace for action disputes. Audio can be sensitive data, so retention must obey consent and data policy.

5. When can a tool decision begin?

Incremental recognition can support low-risk preparation, such as anticipating an order lookup. A committed side effect needs full context and independent authority. A prefix temporarily recognized as 'cancel' may become 'do not cancel' after later speech arrives. Even when user identity and permission are established, the model still needs parameter checks and postcondition verification. If identity cannot be independently established, a similar voice or 'sounds like the boss' cannot grant high-risk permission. Part 2 will examine when a turn is considered complete and how interruption works.

04

Essential mathematics: sample rate to model time steps

A mono waveform lasting T seconds at sampling rate f_s hertz has approximately N=f_s·T samples. f_s is measurements per second, not model tokens per second. At 16 bits per sample, uncompressed payload is B≈N·16/8 bytes. Ten seconds at 16 kHz gives 160,000 samples and about 320,000 bytes; two channels double it. This accounts for input bandwidth, not codec bitrate, inference billing, or recognition quality.

If acoustic features advance one frame every H samples, frame rate is approximately r≈f_s/H. With 16 kHz sampling and H=160, that is about 100 frames per second, or about 1000 frames in ten seconds. A short-time Fourier transform estimates each frame's spectral energy; Mel filters and a logarithm produce a two-dimensional feature. Write the sketch as M=log(ε+Mel(|STFT(x)|²)): x is waveform, STFT is a short-time spectrum, squared magnitude is power, Mel is a filter bank, and ε keeps the logarithm defined at zero. This loses phase and compresses frequency detail. A later encoder may subsample further. Acoustic frames are not identical to LLM input tokens.

In an autoregressive ASR decoder, a text sequence y conditioned on audio representation x factors as P(y|x)=∏ₜP(yₜ|y₍<ₜ₎,x). yₜ is the current text token, and prior transcript tokens influence later predictions. A local misrecognition can therefore change the sentence. This is one generative transcription design, not every ASR objective. Save time-aligned candidates and final text, and raise confirmation thresholds for negations, amounts, names, and tool parameters.

05

Agent implications: separate evidence, identity, and action

A speech-input tool should return a structured observation: audio-segment ID, start and end time, sampling and preprocessing version, ASR candidates or audio-token route, speaker segments, finalization state, and retention policy. The downstream LLM should not see only a time-stripped line of text. For high-risk tasks, it needs to know which words are uncertain, whether speakers overlap, and whether the utterance is partial or final. Keeping only codec tokens without an auditable transcript or semantic record can also make later investigation of a tool action harder.

Independent authorization sits between intent and tool invocation. Spoken content can propose 'cancel the order' but cannot grant order permissions through a voiceprint or a background announcement. For amounts, negation, contacts, and deletion, repeat the exact parameters for confirmation or require an already strong authenticated session or approval. Bind confirmation to specific parameters and observation version; otherwise the user may confirm an old transcript while the agent executes a revised intent.

Compare an ASR→LLM→TTS cascade with a more direct audio model under matched tasks, authority, language and accent, noise, and tool contract. Separately measure transcript and semantic errors, speaker attribution, prosody-sensitive cases, tool-argument accuracy, time to first response and terminal latency, interruption recovery, and cost per verified outcome. Report 'sounds natural' separately from 'uses tools safely.' More fluent speech can mask the same misunderstanding of intent.

06

Trade-offs and failure modes

  • A transcript is the original audio: speaker, prosody, pauses, and noise can disappear. Retain controlled audio references when justified.
  • Audio tokens equal text tokens: codec symbols represent acoustic segments, not a one-to-one mapping to words. Do not cost them using a text-token ledger.
  • Partial ASR may execute actions: later speech can add negation or correction. Wait for finalized intent and authority for high-risk actions.
  • A joint model inherently understands tone: preserving sound does not prove training coverage or correct use at inference. Test the task.
  • The voice sounds authorized: replay, loudspeakers, and imitation exist. Use independent identity and permission gates.
  • Low WER means safe tool use: average word error rate can hide decisive errors in amount, name, or negation. Measure arguments and terminal outcomes.
  • Retain every recording for debugging: sensitive voice and third-party speech require consent, bounded retention, and least access.

A cascade offers a clearer text audit point but can propagate ASR errors. A more direct speech path can preserve acoustics while complicating verification and attribution. Neither dominates across every language, noise condition, risk level, and realtime target.

07

Reusable technical judgments

  • Waveforms, acoustic frames, transcripts, and codec tokens are distinct representations, not interchangeable tokens.
  • ASR→LLM→TTS offers a text audit boundary but propagates transcription loss; joint audio paths retain different cues at new cost.
  • A partial transcript is a revisable hypothesis, not authority to execute a high-risk tool.
  • Verify spoken content, speaker identity, and tool permission separately; voice or tone alone cannot authorize.
  • Slice evaluation by negation, amount, names, noise, and overlap, then judge verified task outcomes.
08

Primary sources and evidence tiers

  • Robust Speech Recognition via Large-Scale Weak Supervision (Whisper) — the authors study log-Mel-based recognition and translation tasks; accuracy belongs to their evaluations.
  • High Fidelity Neural Audio Compression (EnCodec) — the authors develop neural compression and discrete codec representations.
  • AudioLM — the authors study audio-token language modeling for generation, not every speech-agent architecture.
  • SpeechT5 and AudioPaLM — the authors explore distinct shared or joint speech/text modeling designs.
  • Moshi — the authors report a real-time speech-text dialogue model; latency and interaction results belong to its system experiments.

The speech-observation schema, tool authority gate, and task slices are editorial engineering designs. The papers do not prove permission safety or real-time performance for a particular speech product.

Established and next starting point

Established today: continuous waveforms are sampled and converted to acoustic features or discrete neural-codec representations. ASR→text LLM→TTS and joint speech-text paths are different design families. A transcript can lose prosody or speaker cues and pass a wrong word into a tool. Codec tokens are not text tokens; acoustic retention does not guarantee understanding. Partial text, speaker attribution, and tool authorization need separate handling, with high-risk actions waiting for complete intent and outer confirmation.

Still unresolved: an audio stream has no built-in marker that says the user finished. How do voice activity detection, endpointing, streaming ASR, and TTS decide turns and when to answer? After interruption, what happens to already played speech and an in-flight tool?

Next starting point: Audio & Realtime Agent Internals Part 2/3 enters real-time scheduling: chunks, endpoint detection, barge-in, audio/text alignment, tool pauses, and cancellation semantics without repeating today's waveform or acoustic-frame equations.
