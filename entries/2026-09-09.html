LLM 内核 · 第 2/3 篇

一个 token 在 Transformer 内部经历了什么？

打开 decoder-only LLM 的黑盒：从 token embedding、位置编码与 causal self-attention，到 residual stream 和最终 logits。

2026-09-09约 19 分钟LLM / Transformer / Self-attention / Residual stream / Agent context
01

今日命题

昨天我们把模型看成一个函数：给定上下文，输出下一 token 的 logits。今天打开这个函数。对主流 decoder-only LLM，更准确的心智模型不是“每个 token 各自被理解”，而是：所有已有位置都携带一条向量状态；每一层让位置之间受控地通信，再对每个位置独立计算，最后只读取最末位置的状态来预测下一个 token。

一个 token ID 本身只是词表中的整数。embedding 把它变成向量；position 让相同 token 在不同位置表现不同；causal self-attention 让当前位置从过去位置读取信息；MLP 在每个位置上变换特征；residual stream 则像一条贯穿网络的共享总线，让各层不断写入修正。经过许多层后，最后位置的向量被投影回词表空间，得到昨天看到的 logits。

这套机制有两个容易混淆的边界。第一，attention 不是数据库查询：它根据当前激活动态混合上下文中已有位置的 value，不能直接访问训练语料或外部世界。第二，attention weight 不是完整解释：它只描述一次读取中的混合系数，后续 value、output projection、MLP 与 residual addition 都会改变结果。把一张 attention 热图当成模型因果解释，往往比它能支持的结论更强。

今天要建立的边界：Transformer 把上下文压缩成每个位置的连续向量状态，并通过多层受限通信逐步加工；它没有显式、持久、可寻址的“事实表”，也没有越过 runtime 权限边界。
02

连接你熟悉的 Agent context

在 Agent runtime 中，你会构造一串消息：system instruction、用户目标、工具 schema、历史 tool call、tool result，再交给模型。API 层看起来像带角色的对象数组；进入模型前，它们会被模板化并 tokenization，最终成为一个线性 token 序列。角色、消息边界和工具调用标记通常也是 token 或 token pattern，而不是 Transformer 内部独立的安全通道。

因此，模型所谓“看到 context”，实际是每个位置都接收一个初始向量，然后在 causal mask 约束下从左侧位置聚合信息。较晚的用户请求可以读取较早的 system instruction；较晚的 tool result 也可能读取网页里注入的恶意文本。反方向则不成立：早先位置在同一次 forward pass 中不能读取未来位置。这种方向性是 next-token generation 成立的基础，却不会自动编码“system 比 tool result 更可信”。authority hierarchy 主要由训练模式和 runtime 拼接约定影响，真正权限仍必须在模型外执行。

还要区分 context 与 memory。context token 会影响本次 forward pass 的激活；会话结束后，这些激活不会自动写回模型参数。把历史再次放进 prompt、从外部 memory store 检索、或做 fine-tuning，才是跨调用保留信息的不同机制。长 context 给的是临时可访问材料，不等于模型拥有稳定、精确、永久的记忆。

03

逐层追踪最后一个位置

以下追踪一次 decoder-only Transformer 的 forward pass。为简化说明，忽略不同模型在 RMSNorm/LayerNorm、bias、并行 residual、grouped-query attention 等实现差异；这些差异影响速度和训练稳定性，但不改变主数据流。

1. Token ID 变成 residual stream 的初始状态

tokenizer 产生长度为 n 的 ID 序列。embedding matrix E 为每个 ID 查出维度为 d 的向量，组成矩阵 X⁰ ∈ Rⁿˣᵈ。这不是词典释义，而是一组训练学到的坐标。一个 token 的语法、语义和格式特征没有固定分区；特征可能分布在许多维度和位置组合中。

模型还必须知道顺序。原始 Transformer 把 sinusoidal positional encoding 加到 embedding。许多现代模型使用 RoPE：它不直接给 residual stream 加一个位置向量，而是按位置旋转 query 和 key 的二维分量，使注意力点积携带相对位置信息。无论具体方案如何，位置不是装饰性 metadata；没有它，self-attention 对 token 排列近似 permutation-invariant，“狗咬人”与“人咬狗”就缺少结构差异。

2. Attention sublayer：当前位置决定读谁、读什么

每层先规范化 residual state，再用三个线性投影生成 query、key、value。对某个 head，位置 i 的 query 与所有允许位置 j ≤ i 的 key 做点积；softmax 把分数变成总和为 1 的权重；这些权重再混合 value。直觉上，query 表示当前位置正在寻找的模式，key 表示某位置愿意以什么模式被匹配，value 表示匹配后真正搬运的内容。query-key 决定 routing，value 决定 payload。

多头 attention 同时运行多个较小的读取通道。一个 head 可能在某些输入上表现出复制分隔符、跟随句法依赖或追踪前文实体的模式，但不能假设每个 head 都有一个稳定的人类标签。各 head 输出拼接后经过 output projection，形成对 residual stream 的一次更新，而不是替换原状态。

3. MLP sublayer：在每个位置上计算

attention 让信息跨位置移动，MLP/FFN 则对每个位置应用相同参数的非线性变换，通常先扩展维度、经过激活或 gated activation，再投影回模型维度。它可以检测输入特征组合并写入新特征。把 attention 简称为“通信”、MLP 简称为“计算”并不完美，却是有用的工程近似：没有 attention，位置之间难以动态交换信息；没有 MLP，多层线性混合的表达能力会受限。

4. Residual stream：各层共享的工作区

在 pre-norm 架构中，一层可粗略写成：x = x + Attention(Norm(x)); x = x + MLP(Norm(x))。加号非常重要。每个 sublayer 贡献一个增量，已有表示仍沿 residual path 前进。这改善深层网络的梯度传播，也允许不同层在同一向量空间中累积、覆盖或组合特征。所谓 residual stream 不是模型源码里必然存在的数据库对象，而是理解这些跨层向量状态的分析框架。

5. 最后位置变成 logits

完成所有层后，对最后位置状态做 final norm，再乘 unembedding matrix，得到词表中每个候选 token 的 logit。很多模型将 input embedding 与 output unembedding 权重绑定，但这不是概念上的必要条件。softmax 和 decoding 选择一个 token；该 token 追加到序列后，模型再次运行。昨天的 autoregressive loop，就建立在今天这条单次 forward path 上。

04

必要数学：attention 是加权读取

设某层规范化后的状态为 X ∈ Rⁿˣᵈ。一个 attention head 使用训练得到的矩阵生成：

Q = XWQ,   K = XWK,   V = XWV

n 是序列长度，d 是模型宽度，head dimension 记为 dₖ。WQ、WK、WV 不是运行时检索表，而是训练学到的线性投影。对所有位置并行计算时，scaled dot-product attention 为：

A = softmax((QKᵀ / √dₖ) + M),   O = AV

QKᵀ 给出每个 query 与每个 key 的相似分数。除以 √dₖ 是为了在维度增大时控制点积尺度，避免 softmax 过早饱和。M 是 causal mask：当 j > i 时加入负无穷，使位置 i 对未来位置的权重变为 0。A 的每一行是一次概率型 routing；O 则是 value 的加权和。

这个公式揭示 attention 的容量限制：每个 head 在每个位置输出固定宽度的向量，无论它读取 20 个还是 20,000 个 token。它不是把全部上下文无损复制到当前状态，而是在当前 query 驱动下压缩。多个重要事实可能竞争有限的表示带宽；信息虽然位于窗口内，也可能没有被正确路由或在后续层中被稀释。

一层的 residual 更新可抽象成：

X′ = X + Attn(Norm(X));   X″ = X′ + MLP(Norm(X′))

这里的加法使各层可以保留 identity path，同时叠加修正。最终，对最后位置 hₙ：

z = WU Norm(hₙ),   P(token=j)=softmax(z)j

WU 把 d 维状态投影到 vocabulary 大小；z 是 logits。注意，只有最后位置直接产生当前的 next-token distribution，但它通过多层 attention 间接汇集了可访问的前文信息。生成新 token 后，序列长度从 n 变为 n+1，再预测下一项。

05

对 Agent 系统的影响

1. Prompt ordering 会改变计算图

把同一句 instruction 放在开头或靠近当前生成位置，不只是文案差异。位置编码、causal direction 和多层 routing 都会变化。靠后的 token 可以读取靠前内容，但信息必须经过有限宽度的 attention/representation 通道。重要约束应简洁、稳定，并在长轨迹中由 runtime 必要时重新呈现；不要假设一次写在最开头就会被无损保留。

2. Tool result 越长，不代表 observation 越强

大量日志扩大可读取集合，也增加竞争项和计算成本。真正需要的错误码可能被几千行重复输出淹没。先由确定性代码提取结构、保留原始引用和 provenance，再把高信号 observation 送入模型，通常比无差别塞满窗口更可靠。

3. Message role 不是硬隔离

system、user、tool 内容最终共同影响 hidden states。特殊 token 和训练可以让模型学会区分角色，却不能像操作系统权限一样阻止低信任文本影响生成。prompt injection 正是利用这种共享计算表面。外部数据应带来源和信任标签，工具执行仍需 policy gate。

4. Hidden state 不是 durable workflow state

模型可能在 residual stream 中暂时表示计划、实体或不确定性，但这些状态不可由 runtime 稳定寻址，也会在调用结束后消失。任务阶段、已执行副作用、幂等键、审批与恢复点应保存在显式状态机或数据库里，而不是寄希望于“模型记得”。

5. Context window 是上限，不是保证

一个事实位于可接受的 token 范围内，只说明数学上可以被 attention 读取，不说明模型必然选择它、正确组合它或在最终 logits 中保留它。Agent eval 应专门改变关键事实的位置、干扰项数量和 observation 长度，而不是只在理想短 prompt 上测试。

06

取舍与失败模式

全局 attention 的表达力与平方成本：标准 attention 要形成 n×n 的 score 关系，训练或 prefill 的计算/显存随序列长度快速增长。FlashAttention 等实现减少内存读写并避免显式物化完整矩阵，但没有把语义问题变成免费；稀疏、局部或线性 attention 则以不同方式牺牲任意位置间直接交互。

绝对位置、相对位置与外推：learned absolute embedding 简单，却绑定训练过的位置范围；sinusoidal encoding 有解析结构；RoPE 让点积自然带相对位置信号，并成为许多 decoder LLM 的选择。任何方案在超出训练长度时都可能退化。把模型配置中的 context limit 调大，不等于它学会在新长度上可靠推理。

可见不等于可用：研究中常见“lost in the middle”现象：模型对长输入中间位置的信息利用弱于开头或结尾。具体程度依模型、任务和训练而异，不能把它当成所有模型固定曲线；工程上应通过目标模型 eval 决定是否重排、摘要或检索，而非凭传说设计。

attention weight 的解释陷阱：高权重说明某个 head 在该层将更多 value 混入当前位置，不等于该 token 对最终答案具有最大因果影响。value 可能接近零，output projection 可抵消它，后续层也能覆盖它。需要因果干预、activation patching 或端到端行为测试，才可提出更强解释。

压缩与污染是一体两面：attention 能把远处信息路由到当前状态，也能把 prompt injection、错误工具输出和无关模式路由进来。模型内部没有通用的“可信 attention”。Agent runtime 需要在进入 context 前做 provenance、隔离、解析和最小化暴露。

最常见的误判：“在窗口里”被当成“模型会记住”；“attention 到它”被当成“它导致了答案”；“角色 token 不同”被当成“权限隔离”。三者都把统计计算表面误当成确定性系统边界。
07

可复用判断

  • decoder-only Transformer 的每层交替进行跨位置通信（attention）和位置内计算（MLP），并把增量写回 residual stream。
  • query-key 决定读取路由，value 携带被混合的内容；attention weight 本身不是最终答案的完整因果解释。
  • causal mask 只阻止读取未来 token，不编码消息信任等级；Agent 的权限和数据边界必须由 runtime 保证。
  • context window 给出可访问范围，而非检索、记忆或正确使用的保证；长 observation 需要结构化、压缩和位置敏感 eval。
  • 模型 hidden state 是一次调用中的临时计算状态；durable task state、幂等性和恢复点必须显式外置。

LLM Internals · Part 2 of 3

What Happens to a Token Inside a Transformer?

Open the decoder-only LLM black box: from token embeddings, positional information, and causal self-attention to the residual stream and final logits.

2026-09-0919 min readLLM / Transformer / Self-attention / Residual stream / Agent context
01

Today's proposition

Yesterday we treated the model as a function that maps context to next-token logits. Today we open that function. For a modern decoder-only LLM, the useful mental model is not that each token is understood in isolation. Instead, every existing position carries a vector state; each layer lets positions communicate under constraints and then computes locally at every position; finally, the state at the last position is read to predict the next token.

A token ID is merely an integer in a vocabulary. An embedding turns it into a vector; positional information makes the same token behave differently at different locations; causal self-attention lets the current position read from earlier positions; an MLP transforms features independently at each position; and the residual stream acts like a shared bus through the network, with every layer writing an update. After many layers, the vector at the final position is projected back into vocabulary space to produce the logits from yesterday.

Two boundaries are easy to blur. First, attention is not a database query. It dynamically mixes values already represented at context positions; it cannot directly consult the training corpus or the external world. Second, attention weights are not a complete explanation. They describe mixture coefficients for one read operation, while value vectors, output projections, MLPs, and later residual additions all alter the result. Treating an attention heat map as a causal account generally claims more than the mechanism supports.

The boundary to establish today: a Transformer compresses context into continuous vector states and refines them through many layers of constrained communication. It contains no explicit, persistent, addressable fact table, and it never crosses the runtime's permission boundary.
02

Connect it to the agent context you know

In an agent runtime, you assemble system instructions, a user goal, tool schemas, prior tool calls, and tool results, then send that message sequence to the model. The API exposes role-tagged objects, but before inference they are formatted and tokenized into one linear token sequence. Roles, message boundaries, and tool-call markers are generally tokens or token patterns, not physically separate security channels inside the Transformer.

When we say the model sees context, every position actually starts with a vector and then aggregates information from positions to its left under a causal mask. A later user request can read an earlier system instruction; a later tool result can also read malicious language embedded in a web page. The reverse direction is blocked: an earlier position cannot read future positions in the same forward pass. This directionality enables next-token generation, but it does not inherently encode that system text is more trustworthy than tool output. Training patterns and runtime formatting influence authority behavior; actual permissions must still be enforced outside the model.

Context must also be separated from memory. Context tokens affect activations during this inference call; when the call ends, those activations are not automatically written into model parameters. Re-inserting history into a prompt, retrieving from an external memory store, and fine-tuning are different persistence mechanisms. A long context provides temporarily accessible material, not stable, exact, permanent memory.

03

Trace the final position layer by layer

The following traces one forward pass through a decoder-only Transformer. To keep the mechanism visible, we set aside implementation differences such as RMSNorm versus LayerNorm, bias terms, parallel residual branches, and grouped-query attention. Those choices affect efficiency and training stability, but the main dataflow remains recognizable.

1. Token IDs initialize the residual stream

The tokenizer produces a sequence of n integer IDs. An embedding matrix E looks up a vector of width d for every ID, producing X⁰ ∈ Rⁿˣᵈ. An embedding is not a dictionary definition. It is a learned coordinate vector. Syntax, meaning, and formatting are not stored in fixed compartments; features may be distributed across many dimensions and combinations of positions.

The model must also represent order. The original Transformer added sinusoidal positional encodings to token embeddings. Many modern models use rotary position embeddings, or RoPE. Rather than simply adding a position vector to the residual stream, RoPE rotates pairs of query and key coordinates according to position, so their dot product carries relative-position structure. Whatever the specific scheme, position is not decorative metadata. Without it, self-attention is approximately permutation-equivariant and has little basis for distinguishing “dog bites human” from “human bites dog.”

2. The attention sublayer: each position decides where and what to read

At each layer, the residual state is normalized and passed through three learned linear projections that produce queries, keys, and values. For one attention head, the query at position i is dotted with keys at every allowed position j ≤ i. A softmax converts those scores into weights that sum to one, and the weights mix the value vectors. A useful intuition is that a query describes the pattern the current position is looking for, a key describes how a position can be matched, and a value contains what is actually transported after a match. Query-key similarity controls routing; values carry the payload.

Multi-head attention runs several smaller read channels in parallel. On particular input distributions, a head may exhibit behavior such as copying a delimiter, following a syntactic dependency, or tracking an earlier entity. It is unsafe, however, to assume that every head has one stable human-readable job. The head outputs are concatenated and passed through an output projection. The result becomes an update to the residual stream rather than replacing the prior state.

3. The MLP sublayer: compute independently at each position

Attention moves information between positions. The MLP, or feed-forward network, applies the same nonlinear transformation independently to every position. It usually expands the hidden width, passes activations through a nonlinearity or gated activation, and projects back to the model width. It can detect combinations of incoming features and write new features. Describing attention as communication and the MLP as computation is imperfect but useful: without attention, positions cannot dynamically exchange information; without nonlinear MLPs, repeated linear mixtures would have limited expressive power.

4. The residual stream: a shared workspace across layers

In a pre-normalization architecture, one layer can be sketched as x = x + Attention(Norm(x)); x = x + MLP(Norm(x)). The plus signs matter. Each sublayer contributes an increment while the prior representation continues down the residual path. This improves gradient flow through deep networks and lets different layers accumulate, overwrite, or combine features in a shared vector space. The residual stream is not necessarily a database object named that way in model source code; it is an analytical frame for the vector state carried across layers.

5. The final position becomes logits

After all layers, the final position is normalized and multiplied by an unembedding matrix, yielding one logit for every vocabulary candidate. Many models tie the input embedding and output unembedding weights, although weight tying is not conceptually required. Softmax and the decoding policy select a token. That token is appended to the sequence, and the model runs again. Yesterday's autoregressive loop is built from repeated executions of today's single forward path.

04

Essential math: attention is a weighted read

Let the normalized state entering an attention sublayer be X ∈ Rⁿˣᵈ. One attention head uses learned matrices to produce:

Q = XWQ,   K = XWK,   V = XWV

Here n is sequence length, d is model width, and the head dimension is dₖ. WQ, WK, and WV are learned linear projections, not runtime lookup tables. When all positions are computed in parallel, scaled dot-product attention is:

A = softmax((QKᵀ / √dₖ) + M),   O = AV

QKᵀ contains the similarity score between every query and key. Dividing by √dₖ controls the scale of dot products as dimensionality grows, preventing the softmax from saturating too early. M is the causal mask: it contributes negative infinity when j > i, making the weight from position i to a future position zero. Each row of A acts like probabilistic routing; O is the corresponding weighted sum of values.

The equation exposes a capacity constraint. Each head emits a fixed-width vector at each position whether it reads 20 tokens or 20,000. It does not copy the full context losslessly into the current state; it compresses under the current query. Several important facts can compete for limited representational bandwidth. Information can be physically inside the context window yet fail to be routed correctly or become diluted by later computation.

A residual block can be abstracted as:

X′ = X + Attn(Norm(X));   X″ = X′ + MLP(Norm(X′))

The additions preserve an identity path while allowing each sublayer to contribute a correction. Finally, for the last position hₙ:

z = WU Norm(hₙ),   P(token=j)=softmax(z)j

WU projects a width-d state into vocabulary size, and z contains the logits. Only the final position directly produces the current next-token distribution, but through repeated attention it can indirectly gather accessible information from the prefix. After one token is emitted, sequence length grows from n to n+1, and the model predicts again.

05

Implications for agent systems

1. Prompt ordering changes the computation graph

Putting the same instruction at the beginning or near the current generation point is not merely a copy-editing difference. Position encoding, causal direction, and routing across layers all change. Later tokens can read earlier material, but that material must travel through fixed-width attention and representation channels. Critical constraints should be concise and stable, and the runtime may need to re-present them during long trajectories. Do not assume that one statement at the beginning is preserved losslessly forever.

2. A longer tool result is not necessarily a stronger observation

Large logs expand the readable set, but they also add competing candidates and computation. The decisive error code can be buried under thousands of repetitive lines. Deterministic preprocessing that extracts structure, preserves raw references and provenance, and sends a high-signal observation is often more reliable than filling the window indiscriminately.

3. Message roles are not hard isolation boundaries

System, user, and tool content ultimately influence shared hidden states. Special tokens and training can teach the model to treat roles differently, but they do not prevent low-trust text from influencing generation the way an operating-system permission boundary would. Prompt injection exploits this shared computational surface. External data needs provenance and trust metadata, while tool execution still requires an out-of-model policy gate.

4. Hidden state is not durable workflow state

A model may temporarily represent a plan, entity, or uncertainty in its residual stream, but the runtime cannot reliably address those features and they disappear after the call. Task phase, completed side effects, idempotency keys, approvals, and recovery checkpoints belong in an explicit state machine or database, not in the hope that the model remembers.

5. Context window size is a limit, not a guarantee

A fact being inside the accepted token range means attention can mathematically read it. It does not mean the model will select it, combine it correctly, or preserve it into final logits. Agent evaluations should vary the position of critical facts, the number of distractors, and observation length rather than testing only ideal short prompts.

06

Trade-offs and failure modes

Expressive global attention versus quadratic cost: standard attention relates n queries to n keys, and training or prefill cost grows quickly with sequence length. Implementations such as FlashAttention reduce memory traffic and avoid materializing the full score matrix in slow memory, but they do not make semantic use of context free. Sparse, local, and linear attention variants trade away unrestricted direct interaction in different ways.

Absolute position, relative position, and extrapolation: learned absolute embeddings are simple but tied to positions observed during training. Sinusoidal encodings provide analytic structure. RoPE makes dot products carry relative-position information and is widely used in decoder LLMs. Every scheme can degrade outside its training regime. Increasing a configured context limit does not mean the model has learned reliable reasoning at the new length.

Visible does not mean usable: long-context studies often find a “lost in the middle” pattern, where information in the middle of a long input is used less reliably than material near the beginning or end. The magnitude depends on model, task, and training; it is not a universal fixed curve. Engineers should use evaluations on the target model to decide whether to reorder, summarize, or retrieve context rather than designing from folklore.

The attention-weight interpretation trap: a high weight means one head at one layer mixed more of a position's value into the current output. It does not prove that token had the greatest causal effect on the final answer. The value may be near zero, the output projection may cancel it, and later layers may overwrite it. Stronger explanations require causal intervention, activation patching, or end-to-end behavioral tests.

Compression and contamination are two sides of routing: attention can route a distant constraint into the current state, and it can route prompt injection, erroneous tool output, or irrelevant patterns as well. There is no general-purpose trusted-attention channel inside the model. The agent runtime must establish provenance, isolation, parsing, and least exposure before data enters context.

The recurring category error: treating “inside the window” as “the model will remember,” treating “attended to” as “caused the answer,” or treating distinct role tokens as permission isolation. All three mistake a statistical computation surface for a deterministic system boundary.
07

Reusable judgments

  • Every decoder-only Transformer layer alternates cross-position communication through attention with per-position computation through an MLP, adding both updates to the residual stream.
  • Query-key similarity controls read routing and values carry mixed content; attention weights alone are not a complete causal explanation of the final answer.
  • A causal mask blocks future tokens but does not encode message trust. Agent permissions and data boundaries must be enforced by the runtime.
  • A context window defines the accessible range, not guaranteed retrieval, memory, or correct use. Long observations need structure, compression, and position-sensitive evaluation.
  • Model hidden state is temporary computation within one call. Durable task state, idempotency, and recovery checkpoints must remain explicit and external.
08

Primary sources

  • Vaswani et al., Attention Is All You Need — the original treatment of the Transformer, scaled dot-product and multi-head attention, positional encoding, and residual connections. Today's central equations come from this paper. Its architecture is encoder-decoder rather than identical to a modern decoder-only LLM.
  • Brown et al., Language Models are Few-Shot Learners — describes GPT-3's decoder-style autoregressive Transformer, in-context learning setup, and scaling. Reported behavior in the paper is not a guarantee for every later model.
  • Su et al., RoFormer: Enhanced Transformer with Rotary Position Embedding — introduces RoPE and explains how rotating queries and keys expresses relative position. Modern implementations have variants, so a specific model's configuration and source remain authoritative.
  • Elhage et al., A Mathematical Framework for Transformer Circuits — develops the residual-stream, attention-head, and path-expansion analysis used in mechanistic interpretability. It is a research framework, not a completed explanation of all internal semantics.
  • Liu et al., Lost in the Middle — reports position effects on multi-document question answering and key-value retrieval. We treat it as a risk signal requiring evaluation on the target model, not as a universal law.
09

Where we continue tomorrow

Established today: token embeddings and position initialize the residual stream; every layer performs constrained cross-position reads with causal self-attention and nonlinear per-position computation with an MLP; those updates accumulate until the final position is unembedded into logits. We also separated context visibility, attention routing, role trust, and durable state.

Still unresolved: if the full computation repeats for every generated token, how can long conversations be practical? The final LLM Internals installment will separate prefill from decode, unpack the time and memory cost of the KV cache, explain batching and context length in multi-turn agent tool loops, and connect all three parts into one execution model.
